⚙️ Impostazioni repository (salvate nel browser)

Il token GitHub serve nel browser per gestire i prodotti su GitHub. Se usi un Cloudflare Worker per aggirare il blocco IP di Amazon, inserisci qui URL e Key: il “Check ora” userà il Worker (che ha le sue credenziali), mentre l'aggiunta/rimozione prodotti resta su GitHub. Nessun dato viene inviato a terzi.

Esporta un file JSON con TUTTE le impostazioni (inclusi Token e Key): salvalo e re-importalo da un'altra sessione o da anonimo per non riscrivere tutto. ⚠️ Il file contiene segreti: conservalo in un posto sicuro.
